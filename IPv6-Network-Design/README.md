# IPv6 Network Design and Configuration

## Project Overview

This project demonstrates the design and configuration of an IPv6 network using Cisco Packet Tracer.

## Technologies and Concepts

- IPv6 Addressing and Subnetting
- OSPFv3 Routing
- VLAN Configuration
- Frame Relay
- DLCI Configuration
- WAN and LAN Connectivity
- Router and Multilayer Switch Configuration

## Practical Work

- Designed an IPv6 network topology.
- Configured IPv6 addresses on network devices.
- Configured OSPFv3 for dynamic routing.
- Implemented Frame Relay encapsulation and subinterfaces.
- Configured DLCI numbers for WAN connections.
- Tested network connectivity using ping commands.

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
