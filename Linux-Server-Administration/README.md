# Linux Server Administration and Configuration

## Project Overview

This project demonstrates the installation, configuration and management of Linux servers using Ubuntu Server and Ubuntu Desktop in a virtual environment.

## Technologies and Concepts

- Ubuntu Server and Ubuntu Desktop
- Oracle VirtualBox
- NAT Network Configuration
- IP Address Configuration
- DNS Server Configuration
- FTP Server (vsftpd)
- Apache2 Web Server
- Postfix Mail Server
- POP3 and IMAP

## Practical Work

- Created and configured virtual machines.
- Configured network connectivity between virtual machines.
- Assigned IP addresses manually.
- Installed and configured DNS services.
- Set up an FTP server and tested file transfers.
- Installed and configured an Apache2 web server.
- Configured email services using Postfix, POP3 and IMAP.

## Tools Used

- Ubuntu Linux
- Oracle VirtualBox
- Windows XP
- Linux Command Line
